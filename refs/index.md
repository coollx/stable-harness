| Harness-R1 | *Harness-R1: Learning to Edit Executable Runtime Harnesses from Agent Failure Trajectories* ([paper.pdf](related-work/Harness-R1/paper.pdf)) | method | ✅ [repo/](related-work/Harness-R1/repo) · [src](https://github.com/DeepExperience/Harness-R1) | Post-trains a dedicated 9B harness engineer (cold-start SFT on 877 filtered teacher patches, then online GRPO with 8 candidates per failure packet) to read a frozen target agent's failure traces and emit sandboxed Python hooks at four episode-lifecycle points (episode start, pre-decision, pre-action, post-feedback); the reward installs the patch and reruns the same batch with the same frozen target, making it the purest horizon gamma = 0 objective in this index and additionally the inverse of score-before-update. | Meta-Harness | *Meta-Harness: End-to-End Optimization of Model Harnesses* ([paper.pdf](related-work/Meta-Harness/paper.pdf)) | method | ✅ [repo/](related-work/Meta-Harness/repo) · [src](https://github.com/stanford-iris-lab/meta-harness) | Outer-loop search over harness code: a coding-agent proposer (Claude Code on Opus 4.6) reads the source, scores, and raw execution traces of every prior candidate through a filesystem (a median 82 files per iteration, ~10 MTok of history against 0.002–0.026 MTok for prior text optimizers) and writes new single-file harnesses, selected by Pareto dominance on a fixed search set.
